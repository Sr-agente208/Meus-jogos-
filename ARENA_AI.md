# ARENA_AI.md

## Objetivo
Este arquivo orienta qualquer IA responsável por desenvolver este repositório.

## Prioridade máxima
1. Nunca quebrar funcionalidades existentes.
2. Fazer commits pequenos.
3. Documentar mudanças.
4. Manter código organizado.

## Estrutura
- docs/: documentação
- assets/: imagens, áudio e modelos
- src/: código-fonte
- builds/: versões exportadas
- notes/: anotações

## Fluxo recomendado
1. Ler README.md.
2. Ler PROJETO.txt.
3. Planejar antes de alterar código.
4. Implementar uma funcionalidade por commit.
5. Testar antes de finalizar.

## Convenções
- Nomes de arquivos em inglês quando forem código.
- Evitar duplicação de lógica.
- Comentar apenas trechos complexos.
- Separar lógica, interface e dados.

## Commits
- feat:
- fix:
- docs:
- refactor:
- style:
- chore:
- assets:

## Mundo Torajo
Caso trabalhe neste projeto:
- preservar a narrativa existente;
- implementar sistemas de forma modular;
- manter eventos, entidades e IA desacoplados;
- documentar cada mecânica adicionada.

## Regra final
Quando houver dúvida entre velocidade e qualidade, priorize qualidade, estabilidade e documentação.
