# 🎮 Meus-jogos-

> Repositório principal para centralizar projetos, ideias e documentação de desenvolvimento de jogos.

## Sobre

Este repositório funciona como um **hub de desenvolvimento**, reunindo projetos completos, protótipos, Game Design Documents (GDD), artes conceituais, roteiros, mecânicas e experimentos criados durante estudos e projetos pessoais.

O objetivo é manter tudo organizado, documentado e versionado usando Git e GitHub.

## Objetivos

- Centralizar todos os projetos de jogos
- Organizar códigos e documentação
- Armazenar protótipos
- Registrar a evolução dos projetos
- Facilitar futuras atualizações
- Servir como portfólio de desenvolvimento

## Guia rápido para o Arena IA

Se você é o Arena IA e vai continuar este projeto:

1. Leia primeiro o `README.md` e o `PROJETO.txt`.
2. Entenda a estrutura antes de criar arquivos novos.
3. Prefira commits pequenos e com propósito claro.
4. Separe documentação, código e assets.
5. Não sobrescreva arquivos importantes sem necessidade.
6. Mantha nomes consistentes de pastas e arquivos.
7. Quando adicionar uma função nova, atualize a documentação junto.
